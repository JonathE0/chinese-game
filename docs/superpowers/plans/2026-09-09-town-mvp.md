# Mandarin Town MVP Implementation Plan

**Goal:** A locally playable, extensible Mandarin town with exploration, player-initiated dialogue, vocabulary practice, persistent spaced review, and shopping.

**Architecture:** PlayCanvas standalone engine renders modular procedural low-poly assets using editable world data. Browser HTML overlays provide accessible interfaces. Pure JavaScript domain modules own lesson matching, review scheduling, economy, and validated persistence. A local layout tool edits NPC/building positions and exports JSON; this is not a synchronized hosted PlayCanvas Editor project.

**Tech Stack:** PlayCanvas 2.22.1, Vite, JavaScript modules, JSON content, Node tests, Playwright browser tests.

**Spec:** ../specs/2026-09-09-mandarin-town-square-design.md

## Constraints and known delivery boundary

Chinese first; settings configure what a contextual help button reveals. NPCs never initiate required dialogue. Voice input is optional and editable before submission. Authored human-quality voice assets are not available in this workspace: deliver the recorded-audio adapter, asset manifest and recording script, explicit unavailable states, and report spoken audio as incomplete. No browser TTS substitution. Do not label unverified content as officially HSK-aligned. Local profile includes export/import and no server accounts. Food/housing and the complete HSK curriculum remain roadmap work.

Contracts: `matchAnswer(text,node)` returns `{ok,value}` or `{ok:false}`; `reviewWord(profile,id,skill,{correct,hinted,now})` updates a specific skill and rewards eligible correct reviews; `grant(profile,key,amount)` is idempotent; `negotiate(item,current,round,text)` returns an optional new quote and round; `purchase(profile,item,quote)` validates and updates wallet and inventory together; `decodeProfile(raw)` returns a validated profile.

Schedule: first unassisted success due in ten minutes, next in one day, then three days, seven days, fourteen days, thirty days. A hinted answer cannot advance the stage and returns in ten minutes. An incorrect attempt returns in two minutes and reduces stage by one, retaining history. Practice before due does not advance scheduling or award coins. Only due unassisted correct reviews earn three coins; due supported successes earn one. First lesson completion awards twenty coins (ten supported); a first practice completion awards eight coins when all four words have been answered correctly. No recurring completion reward. Fresh wallet starts at zero. All values live in balance data.

### Decisions worth recording

**Voice provider.** `edge-tts` was chosen because it produces genuinely natural Mandarin with eight distinct voices, needs no API key, and is provider-shaped so it can be swapped. Its licensing is *not* cleared for redistribution — this is recorded in the README and the voice doc as a blocker for publishing, not for local play.

**Two HSK standards, never mixed.** The spec forbids silently merging classic and revised HSK. The dataset tags both, so HSK 3.0 drives the hall and classic HSK 2.0 rides along in `legacyLevel`, shown as a separate badge. The unverified status is stated on screen, not just in the docs.

**Dictionary licensing.** CC-CEDICT is CC BY-SA 4.0. Attribution is rendered inside the popup itself rather than buried in the README, because share-alike follows the data.

**Music is synthesised, not sourced.** Borrowing a track from the internet would have meant an unresolvable licensing question for an asset the player hears constantly. A ~90-line Web Audio score has none, never loops audibly, and costs nothing to ship.

**Third person was kept.** "Immediately switch to first person" is the default, but deleting third person entirely would have silently removed the visibly wearable hat the MVP already paid for. V toggles.

### Decisions worth recording

**One registry, three jobs.** Collision, ground height and look-at all want the same information, so they share one box list rather than three parallel structures. Registering a prop gives it a hitbox, something to stand on, and a Chinese name in a single call.

**Naming is Chinese-first.** The nameplate shows only the characters until you press F. That keeps the spec's rule — Chinese by default, help on request — while making F worth pressing.

**Gates count breadth, not waiting.** Requiring stage-3 mastery would have blocked players for real days, since stage 3 needs reviews spaced over 24 hours. Instead a word counts once answered correctly, and the bar is a large number of words. Naming things in the world counts too, so exploring and drilling both move it.

**Fixed prices are a teaching point.** Only Chen's street stall haggles. The shops say 明码标价 and refuse to negotiate, which is how they actually work.

**A debug handle for tests.** Browser tests used to steer to a door with hard-coded key holds, and broke every time the map moved. `window.__qinghe` lets them place the player and then walk the last couple of metres, so collision and prompts are still exercised for real.

### Bugs found and fixed

**Placing furniture reported the wrong thing.** Clicking an occupied spot ran the same path as cancelling, so the piece vanished and the game said "cancelled". That was the reported bed bug. Blocked and cancelled are now separate, the piece stays in hand, and a heads-up display shows green or red while you move.

**Only one lamp kind actually lit anything.** `addProp` attached a light for `kind==='lamp'` only, so the ceiling and desk lamps were decorative - which would have made the whole lighting shop pointless. Caught by a test that asserted the light exists.

**The pointer-lock spin.** Browsers can emit one enormous `movementX` on the frame pointer lock engages; at 0.12 sensitivity a 4000px delta is eleven full turns. The first delta after locking is now dropped if it is implausible, and every delta is clamped to a real-mouse range.

**Getting wedged in geometry.** Collision had no recovery: a prop registered where you stood, or a spawn inside something, meant being frozen for good. The player now walks out toward the nearest free spot, and furniture can no longer be placed on the square you are standing on.

**Jumping could not clear anything.** Jump height sat below the bench top and the pond was a solid wall. Jump apex is now 1.02 m - enough for benches and planters, not for a district wall - and the pond is shallow enough to wade.

**An NPC blocking a doorway.** Giving NPCs hitboxes left Xiaomei standing in the word hall's only entrance.
